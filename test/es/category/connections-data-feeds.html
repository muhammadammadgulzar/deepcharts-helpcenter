🔌 Conexiones y fuentes de datos

Conecte todos los brókeres, empresas prop y fuentes de datos compatibles, y solucione los problemas de conexión.

Configuración inicial
  • Brókers, empresas prop y fuentes de datos compatibles
    Todos los brókers, empresas prop y fuentes de datos que se conectan a DeepCharts, con los valores exactos de Feed Source y Server para cada uno.
    beginner
  • Cómo conectar una fuente de datos (Feed Settings)
    Añada una conexión de fuente de datos en Feed Settings, conéctela y obtenga datos en vivo en un gráfico.
    beginner
  • Symbol Manage: suscribir bolsas y asignar su fuente de datos
    Suscriba las bolsas que opera y dirija cada una a la fuente de datos correcta para que los gráficos carguen.
    beginner
  • Firme su acuerdo de datos de mercado
    Dónde y cómo firmar el acuerdo de datos de mercado para cada tipo de cuenta: requerido antes de que cualquier fuente de datos en vivo pueda conectarse.
    beginner
  • Cómo conectar una fuente de datos dxFeed
    Conecte una cuenta dxFeed comprada en el sitio web de DeepCharts o en dxfeed.com, incluida la configuración de DOM Type y Symbol Manage.
    beginner
  • Cómo conectar una fuente de datos de Rithmic
    Conecte una fuente de datos de Rithmic a DeepCharts: firme el acuerdo en R Trader Pro, introduzca sus credenciales con el valor de Server correcto y verifique los gráficos en vivo.
    beginner
  • Conectar Rithmic mediante el plugin de RTrader Pro
    Ejecute R Trader Pro como pasarela de datos para que DeepCharts y otras plataformas compartan una cuenta Rithmic al mismo tiempo sin conflictos de sesión.
    intermediate
  • Conecte cualquier cuenta de empresa prop de Rithmic (tabla de servidores)
    Un único flujo de configuración para todas las empresas prop de Rithmic: busque el valor de Server de su empresa en la tabla, firme el acuerdo en R Trader Pro y conéctese a DeepCharts.
    beginner
  • Cómo conectar Apex Trader Funding
    Conecte su cuenta Rithmic de Apex Trader Funding (Evaluation o Funded) a DeepCharts, desde la firma del acuerdo en R Trader Pro hasta los gráficos en vivo.
    beginner
  • Cómo conectar una cuenta dxFeed de empresa prop (MFF, Aqua, Goat...)
    Conecte una cuenta dxFeed emitida por una empresa prop como MyFundedFutures, Aqua Futures o Goat Funded Futures usando la fuente dxFeed Prop.
    beginner
  • Cómo conectar CQG (AMP, Optimus, EdgeClear, Ironbeam...)
    Conecte una cuenta CQG de AMP Futures, Optimus, EdgeClear, Ironbeam o Phillips Capital a DeepCharts.
    beginner
  • Cómo conectar Interactive Brokers (solo ejecución)
    Conecte Interactive Brokers a través de la TWS API para la ejecución de operaciones, junto con una fuente de datos real para los gráficos.
    intermediate
  • Competición de DeepCharts: únase y conéctese
    Únase a una competición de trading de DeepCharts y conecte la cuenta de concurso V-Sim junto con su fuente de datos.
    beginner
  • Conectar datos históricos (fin de día)
    Configure la fuente de datos Historical para cargar datos de fin de día en sus gráficos.
    beginner
  • Administrar y cambiar entre conexiones de fuente de datos
    Guarde varias conexiones de fuente de datos, cambie entre ellas, ejecute varias a la vez, conéctese automáticamente al iniciar y elimine las antiguas.
    intermediate
Solución de problemas
  • Solución: fuente en vivo conectada pero el gráfico no se mueve
    Qué revisar cuando su fuente de datos aparece como conectada pero el gráfico de precios está congelado, muestra datos antiguos o no muestra datos.
    beginner
  • Solución: Connection Failed — Unable to Establish Connection
    Resuelva el error de fuente de datos 'Unable to establish connection' causado por VPN, componentes de Visual C++ faltantes o una configuración de Windows en un idioma distinto del inglés.
    beginner
  • Solución: Connection Failed — Verifique el nombre de usuario y la contraseña
    Solucione el error de conexión de Rithmic 'check username and password' usando las credenciales de Rithmic correctas y el servidor adecuado para su tipo de cuenta.
    beginner
  • Solución: Connection Failed — Bad Server
    Resuelva el error de conexión 'Bad Server' de dxFeed causado por inicios de sesión simultáneos en varias plataformas o por un acuerdo de datos de mercado sin firmar.
    beginner
  • Solución: Please Log In Using R Trader or R Trader Pro
    Solucione el error de Rithmic que le pide iniciar sesión con R Trader o R Trader Pro firmando una sola vez el Acuerdo de Datos de Mercado de su cuenta.
    beginner
  • Solución: Rithmic — Expert Not Attached
    Resuelva el error 'Rithmic: Expert not attached' que mantiene la conexión de su fuente Rithmic en amarillo en lugar de verde.
    beginner
  • Solución: No se puede cargar la DLL DXFeed_64.dll
    Solucione el error de conexión 'Unable to load DLL DXFeed_64.dll' instalando el Microsoft Visual C++ Redistributable.
    beginner
  • Solución: dxFeed DATA_ACCESS_SUSPENDED
    Restaure el acceso a datos de mercado de dxFeed tras un error DATA_ACCESS_SUSPENDED causado por una revisión del estado Non-Professional.
    beginner
  • Solución: dxfeed.myfundedfutures.com Failed
    Solucione el error 'dxfeed.myfundedfutures.com failed: You need to sign the datafeed' firmando el Acuerdo de Datos de Mercado con su empresa.
    beginner
  • Solución: The System Cannot Find the File Specified
    Solucione el error de conexión 'The system cannot find the file specified' causado por un Volumetrica Bridge ausente o bloqueado por el antivirus.
    beginner
  • Solución: conexión perdida al abrir un gráfico
    Qué hacer cuando su fuente de datos se conecta bien pero la conexión se cae en el momento en que un gráfico empieza a cargar datos.
    beginner
  • Solución: Problema de suscripción de símbolo
    Resuelva un problema de suscripción de símbolo comprobando la conexión de su fuente de datos y reasignando el mercado a la conexión correcta en Symbol Manage.
    beginner
  • Solución: la aplicación se cierra al guardar la configuración de la fuente
    Solucione los cierres inesperados de DeepCharts al hacer clic en Save en Feed Settings: permisos, idioma de Windows o archivos de configuración dañados.
    beginner
  • Solución: gaps de precio en los gráficos
    Elimine los gaps de precio causados por datos locales dañados y aprenda a distinguirlos de los gaps de mercado reales y de los meses de contrato vencidos.
    intermediate
  • Solución: gráficos con retraso o datos demorados (lista de verificación)
    Una lista de verificación paso a paso para diagnosticar datos de gráfico demorados o con retraso: enrutamiento de la fuente demorada, velocidad de descarga regional, DOM Type, gateway de Rithmic y recursos del sistema.
    intermediate
