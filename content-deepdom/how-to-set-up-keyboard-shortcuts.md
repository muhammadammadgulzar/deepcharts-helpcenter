This guide explains how to configure keyboard shortcuts in DeepDom so you can perform common actions faster and improve your workflow.

## Open the Shortcuts Settings

[SCREENSHOT: How to Set Up Keyboard Shortcuts — Open the Shortcuts Settings (DeepDOM) | how-to-set-up-keyboard-shortcuts-01.png]

1. Open the Options menu in DeepDom.
2. Click Settings .

3. Move to the Shortcut column. From this window you can configure the various keyboard shortcuts available on the platform.

## Shortcuts Window Overview

[SCREENSHOT: How to Set Up Keyboard Shortcuts — Shortcuts Window Overview (DeepDOM) | how-to-set-up-keyboard-shortcuts-02.png]

Shortcuts are organized by Category and Type .

### Categories

General – global platform functions.

Chart – actions related to charts and visualizations.

### Types of Shortcut

Action – triggers specific actions or commands.

Control – controls platform navigation or behavior.

Drawing and Annotation – tools for lines, shapes, and other drawings.

Scroll – horizontal or vertical scrolling actions.

Trading – order‑entry or trading‑related commands.

The Shortcut description column shows the key combination currently assigned to each action.

### Configuration Buttons

Next to each action you will find buttons to manage the associated shortcut:

Delete – clears the saved key combination.

Record (or Register) – allows you to record a new combination.

### Create a New Shortcut

Click Record for the action you want to configure.

Press the desired key combination on your keyboard (for example, *Ctrl + Shift + H*).

Check that the new combination appears in the Combination column.

Click Save Settings to store the new shortcuts.

The new keyboard shortcuts are now active and ready to use throughout DeepDom.
