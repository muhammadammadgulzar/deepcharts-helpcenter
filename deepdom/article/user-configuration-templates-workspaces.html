User Configuration – Templates, Workspaces, Tool Config (DeepDom)

DeepDom is highly customizable. You can create Templates for your preferred indicator layouts, Workspaces (Work Plans) to save entire window arrangements, and Tool Configurations to reuse custom annotation styles. This guide explains how to manage each of these elements.

Templates

A Template represents the full set of indicators and visual settings applied to a single tool such as a Heatmap, Advanced DOM, or Time & Sales window. Once saved, a template can be loaded on multiple similar windows to instantly replicate the same layout.

Where Templates Are Saved

By default, DeepDom stores template files in your Documents folder under dedicated sub‑directories, for example:

Heatmap: Documents/DeepDom/Template

Time & Sales: Documents/DeepDom/Time and Sales Template

Advanced DOM: Documents/DeepDom/Adv Dom Template

You can paste into these folders any template files that you download from your personal area on the Volumetric Trading website and then load them directly in DeepDom.

Load a Template

📷

To load an existing template on a Heatmap, Time & Sales, or Advanced DOM window:

Click the Settings (gear) icon in the top‑right corner of the tool window.

Choose load .

Select the desired template file from the dialog.

Click Open to apply it.

Save a Template with Name

📷
Screenshot placeholder
User Configuration — Templates, Workspaces, Tool Config — Save a Template with Name (DeepDOM)
user-configuration-templates-workspaces-02.png

After you customize a tool with your preferred indicators and styles, you can save the setup as a new template:

On the Heatmap or other tool, click the Settings (gear) icon.

Select Template > Save As .

Enter a descriptive file name (for example, Template Volume Profile 30 Min).

Click Save .

The same procedure applies for Time & Sales, Advanced DOM, Scanner, or Correlations windows.

Workspaces (Work Plans)

📷
Screenshot placeholder
User Configuration — Templates, Workspaces, Tool Config — Workspaces (Work Plans) (DeepDOM)
user-configuration-templates-workspaces-03.png

A Workspace (Work Plan) represents the complete arrangement of DeepDom windows – Heatmaps, DOMs, Time & Sales, and other tools – across one or more monitors. Saving a workspace lets you reopen the same layout with a single click when the platform starts.

Managing Work Plans

In the Work Plan Management window you can:

View the list of open work plans.

Save the current configuration of the active work plan.

Save the layout under a new work‑plan name.

Close an existing work plan.

Important Notes

The default work plan is named Untitled and should be saved with a specific name the first time you configure it. When you want to close a work plan, use the dedicated Work Plan Management section and click the X next to its name. Do not close each window individually and then save the plan, otherwise you may accidentally save an empty workspace and lose your open charts.

Tool Config (Custom Annotations)

DeepDom allows you to store multiple configuration profiles for drawing tools (annotations) and choose a default configuration for each annotation type.

Create and Save Annotation Configurations

📷
Screenshot placeholder
User Configuration — Templates, Workspaces, Tool Config — Create and Save Annotation Configurations (DeepDOM)
user-configuration-templates-workspaces-04.png

To create a custom configuration:

Draw an annotation on the chart.

Select the drawing and right‑click on the highlighted handle or dot.

Edit line style, color, extension, text, and other properties as desired, then apply the changes.

Click Configurations to view existing presets.

Click Manage , then Add Configuration to save the current style as a new preset.

Reorder saved configurations so that the first one in the list becomes the Default configuration automatically used for new annotations of that type.

Still Having Trouble?

A screenshot of the issue.

A brief description of what you were trying to do.

Support Ticket (fastest response): visit www.deepcharts.com and create a support ticket directly on our website.

Email Support: you can also reach us at support@deepcharts.com. Please note that email responses may take a little longer than a support ticket.
