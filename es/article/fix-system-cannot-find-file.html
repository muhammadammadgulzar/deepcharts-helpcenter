Solución: The System Cannot Find the File Specified

Solucione el error de conexión 'The system cannot find the file specified' causado por un Volumetrica Bridge ausente o bloqueado por el antivirus.

Beginner Troubleshooting 🕒 10 min to complete ⬇ Download PDF

Este error aparece cuando DeepCharts no puede localizar o iniciar el Volumetrica Bridge, un componente en segundo plano que la plataforma requiere para sus conexiones de fuentes de datos. Durante la instalación, DeepCharts crea automáticamente una carpeta Volumetrica Bridge, y cuando todo funciona correctamente verá el Volumetrica Bridge ejecutándose en segundo plano. Si este error aparece, el Bridge falta o está siendo bloqueado.

Síntoma

Al conectar una fuente de datos, la conexión falla con:

Connection Failed: The system cannot find the file specified

📷
Screenshot placeholder
El cuadro de diálogo de error de conexión mostrando el mensaje completo "Connection Failed: The system cannot find the file specified"
ID: dc-es-fix-system-cannot-find-file-01 · save as dc-es-fix-system-cannot-find-file-01.png

No debe confundirse con:

  • Solución: Could Not Find a Part of the Path: un error de "ruta" diferente, relacionado con la base de datos local, no con el Bridge.
  • Solución: Connection Failed — Unable to Establish Connection: un fallo a nivel de red en el que el Bridge se ejecuta pero no se puede alcanzar el servidor.

Causa más probable

El Volumetrica Bridge falta o está bloqueado: o bien el instalador no logró crear la carpeta Volumetrica Bridge, o bien su antivirus (McAfee en particular) ha puesto en cuarentena VolumetricaBridge.exe.

Consejo: Si usa McAfee u otro antivirus agresivo, revise primero su cuarentena (vea más abajo); de lo contrario, el antivirus puede volver a poner el Bridge en cuarentena justo después de reparar la instalación.

Solución rápida

Repare la instalación para que el instalador vuelva a crear el Bridge faltante:

  1. Cierre DeepCharts por completo.
  2. Localice su instalador original de DeepCharts (.exe). Si ya no lo tiene, descárguelo de nuevo desde la fuente oficial; consulte Cómo instalar DeepCharts y activar su licencia.
  3. Ejecute el instalador y elija la opción Repair.
📷
Screenshot placeholder
La ventana del instalador de DeepCharts con la opción Repair visible y resaltada
ID: dc-es-fix-system-cannot-find-file-02 · save as dc-es-fix-system-cannot-find-file-02.png
  1. Deje que el proceso de reparación termine por completo.
  2. Vuelva a abrir DeepCharts y reconecte la fuente de datos.

En la mayoría de los casos, el error se resuelve tras este paso.

Si eso no funcionó

Causa: McAfee puso en cuarentena VolumetricaBridge.exe

McAfee puede marcar incorrectamente VolumetricaBridge.exe y moverlo a cuarentena. Restáurelo y exclúyalo de futuros análisis:

  1. Cierre DeepCharts por completo.
  2. Abra McAfee Antivirus.
  3. Vaya a Menu → Quarantined Items (elementos en cuarentena).
  4. Busque VolumetricaBridge.exe en la lista y seleccione Restore (restaurar).
📷
Screenshot placeholder
Pantalla de Quarantined Items de McAfee con VolumetricaBridge.exe en la lista y la acción Restore visible
ID: dc-es-fix-system-cannot-find-file-03 · save as dc-es-fix-system-cannot-find-file-03.png
  1. Añada el archivo a las exclusiones del análisis: vaya a Menu → Real-Time Scanning → Add File.
  2. Navegue hasta VolumetricaBridge.exe y selecciónelo. CONFIRM: default installation path of the Volumetrica Bridge folder
📷
Screenshot placeholder
Pantalla de exclusiones de Real-Time Scanning de McAfee después de añadir VolumetricaBridge.exe
ID: dc-es-fix-system-cannot-find-file-04 · save as dc-es-fix-system-cannot-find-file-04.png
  1. Cierre McAfee y vuelva a iniciar DeepCharts.

Nota: Restaure y excluya únicamente archivos que reconozca. VolumetricaBridge.exe es un componente legítimo de DeepCharts.

Causa: Otro antivirus o una política de seguridad está bloqueando el Bridge

Otros productos antivirus pueden poner en cuarentena el Bridge de la misma manera. Revise la cuarentena de su producto, restaure VolumetricaBridge.exe y añádalo a la lista de exclusiones. Si el bloqueo proviene de una política de control de aplicaciones de Windows, consulte Solución: una política de control de aplicaciones bloquea DeepCharts.

Si sigue atascado

Genere un Informe de diagnóstico: antes de contactar con soporte para que soporte pueda ver si el Bridge está presente y en ejecución, y luego contacte al equipo mediante Cómo obtener ayuda (chat, informe de diagnóstico, soporte).

Cómo prevenirlo

  • Instale DeepCharts únicamente con el instalador oficial; consulte Cómo instalar DeepCharts y activar su licencia.
  • No fuerce el cierre del instalador durante la configuración; una instalación interrumpida puede dejar la carpeta del Bridge sin crear.
  • Añada el Volumetrica Bridge a la lista blanca de su software antivirus para que nunca vuelva a ponerse en cuarentena.
