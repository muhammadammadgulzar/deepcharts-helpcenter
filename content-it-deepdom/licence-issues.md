Se hai problemi ad attivare DeepDOM con il tuo codice di licenza, segui la checklist qui sotto. Questi passaggi risolvono la maggior parte dei problemi legati a licenze non valide, sessioni multiple o connessioni bloccate verso il server delle licenze.

### Passaggio 1 – Verifica lo stato del tuo abbonamento

[SCREENSHOT: Problemi di licenza — Passaggio 1 – Verifica lo stato del tuo abbonamento (DeepDOM) | dd-it-licence-issues-01.png]

Verifica che il tuo abbonamento DeepDOM sia attivo nel portale clienti del sito DeepDOM. Gli abbonamenti scaduti o annullati impediscono nuove attivazioni della licenza anche se hai ancora la vecchia email con la licenza.

### Passaggio 2 – Assicurati che sia attiva una sola sessione

Le licenze DeepDOM in genere consentono una sola sessione attiva per licenza. Se la piattaforma è già aperta su un altro computer, o se una sessione precedente non si è chiusa correttamente, il nuovo accesso potrebbe essere rifiutato.

Chiudi DeepDOM su tutte le altre macchine, attendi qualche minuto che la sessione scada e poi riprova. Se necessario, riavvia Windows per assicurarti che non ci siano processi di DeepDOM ancora in esecuzione in background.

### Passaggio 3 – Verifica email e codice di licenza

Copia e incolla con attenzione l'indirizzo email e il codice di licenza dal tuo messaggio di benvenuto nel modulo di attivazione. Evita di digitarli manualmente per prevenire errori come spazi extra, caratteri invertiti o cifre mancanti.

### Passaggio 4 – Controlla la configurazione del file hosts

Il file hosts di Windows mappa i nomi di dominio agli indirizzi IP prima che venga interrogato il DNS. Una voce errata in questo file può impedire a DeepDOM di raggiungere il server delle licenze, anche se la tua connessione a Internet funziona correttamente per il resto.

Se tu o un'altra applicazione avete modificato il file hosts, controllalo e rimuovi eventuali righe che reindirizzano i domini di licenza DeepDOM / Volumetric Trading verso indirizzi IP non validi. Segui sempre una guida affidabile quando modifichi il file hosts e crea un backup prima di apportare modifiche.

### Passaggio 5 – Se i problemi persistono

Se la licenza non si attiva ancora dopo aver completato i passaggi sopra, contatta il supporto con le seguenti informazioni:

Il tuo codice di licenza e l'indirizzo email usato per la registrazione.

Uno screenshot dell'esatto messaggio di errore.

La tua versione di Windows e se di recente hai cambiato hardware o reinstallato il sistema operativo.

Fornire questi dettagli aiuterà il team di supporto a reimpostare o correggere rapidamente la tua licenza se necessario.
